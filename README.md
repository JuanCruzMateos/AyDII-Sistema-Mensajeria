### Requirements

- JDK 21
- Maven 3.9.9

### How to run

Compile and Packege into JAR:

```bash
# Linux / MacOs
./build.sh

# Windows (PowerShell)
./build.ps1
```

Run Server:

```bash
# Linux / MacOs
./run.sh server

# Windows (PowerShell)
./run.ps1 server
```

Run Client:

```bash
# Linux / MacOs
./run.sh client

# Windows (PowerShell)
./run.ps1 client
```
